# Secure DevSecOps Platform

A hands-on, portfolio-ready DevSecOps project focused on building practical experience across cloud-native infrastructure, CI/CD, containers, Kubernetes, infrastructure as code, observability, and security engineering.

## Project Goal

The application will evolve into a simple vulnerability-management API, while the primary focus is the engineering platform surrounding it.

This project is being built incrementally to demonstrate practical experience with:

- Git and GitHub
- Python and FastAPI
- PostgreSQL
- Docker and Docker Compose
- Terraform
- Kubernetes
- CI/CD
- DevSecOps security controls
- Monitoring and observability
- GitOps
- Incident response
- Backup and recovery

## Current Status

Phase 1: Git and application foundation.
